# CodeWizards

A multi-agent web IDE that shows LLM work as a tower of wizards in isometric pixel art, in a style close to the Game Boy Color, with an optional CRT filter. Each project is a room; each agent is a wizard from its guild (its AI provider). *Do not vibecode. Spellcode.*

Domain: `codewizards.app` · Status: milestone 0 (mockup) — simulated agents, no API calls yet.

## Try the mockup

Open `apps/maqueta/maqueta.html` in a browser. Write a spell (a request), press «Lanzar» and watch the wizards come in, read at the library, write at the lab table and present at the blackboard. Approve or reject their work on the board. Everything is simulated; the UI is in Spanish for now.

## Development

```sh
python3 -m pip install -r codewizards-art/04_source/requirements.txt   # numpy, Pillow
python3 codewizards-art/04_source/gen/build.py   # regenerate art, previews and the room demo
python3 codewizards-art/04_source/gen/check.py   # validate art: indexed, 1-bit alpha, RGB555, palettes, colours, names
python3 apps/maqueta/build.py                    # rebuild apps/maqueta/maqueta.html
node apps/maqueta/test/maqueta.test.mjs          # mockup logic, paths and event contract v0
```

CI runs the art check, the mockup tests and verifies that `maqueta.html` matches its sources.

## Event contract v0

The room knows nothing about LLMs: it only replays events (`room.opened`, `task.created`, `agent.summoned`, `agent.assigned`, `context.read`, `code.write`, `artifact.present`, `tokens.used`, `review.requested`, `review.approved`, `review.rejected`, `agent.error`, `task.done`, `agent.idle`). The mockup simulator emits them today; the real backend will emit the same ones. Full table in `docs/agentes.md`.

## Conventions

- Commit messages and READMEs in English; plans, reports and hand-offs in Spanish.
- Commit with `git commit -F COMMIT_MSG.txt`: each delivery brings one, and it is git-ignored.
- The API key never goes into the repo or the browser.
- Art is painted by code, without generative image models, and retouched by hand.
- Integer scaling only (`image-rendering: pixelated`).
