# Búsqueda de la marca CodeWizards · paso 8

30/10/2026 · Búsqueda preliminar en la web y en fichas públicas de registros, hecha por un agente. **No es una búsqueda de marcas profesional ni asesoramiento legal.**

## 0. En pocas líneas

- **El mayor riesgo, en EE. UU.: CODE WIZARD.** Es una marca viva y muy cercana: registro USPTO 2158527, clase 9, para software que analiza, depura y mejora el diseño de otro software, en uso desde 1996.
- **CODEWIZARDSHQ** (USPTO, registro 6134698, clase 41) cubre clases de programación para niños. Es otra clase, pero el nombre se parece mucho.
- **Hay productos de IA para programar con nombres parecidos**, como CodeWiz, que tiene extensión de VS Code.
- **`codewizards` está libre en npm** (el registro respondió 404 el 30/10/2026).
- **Recomendación**: antes de invertir en la marca, una búsqueda profesional en EUIPO/TMview, OEPM y USPTO para las clases 9, 42 y 41, y decidir con ese resultado. Invertir en la marca es pagar publicidad, registrarla o hacer un lanzamiento amplio. Cambiar de nombre ahora es barato; después, caro.

## 2. Lo que no se pudo comprobar

- **EUIPO, TMview y OEPM**: sus buscadores no se pueden consultar desde aquí. Es lo primero que hay que mirar, porque CodeWizards nace en España.
- **El dominio `codewizards.app`**: el DNS no respondió desde el contenedor, y eso no prueba nada. Míralo en tu registrador.
- **La organización `codewizards` en GitHub**: la API respondió 403 desde aquí.
- **Marketplace de VS Code y Open VSX**: el identificador de la extensión lleva el editor delante (`poligle.codewizards`), así que no choca, pero el nombre visible «CodeWizards» puede repetirse.
- **Amber Order, Indigo Lodge y Jade Cloister** (encargo del paso 7): sin buscar.

## 3. Recomendación

1. **Antes de un lanzamiento amplio o de registrar la marca**: búsqueda profesional en las clases 9 y 42, y también la 41, por CodeWizardsHQ.
2. **Mientras tanto**, publicar en npm y en GitHub con el nombre actual es reversible: un paquete de npm se puede deprecar y un repositorio se puede renombrar (GitHub redirige el nombre viejo).
3. **Si hubiera que cambiar**, el lema da una pista («Spellcode»), pero cualquier alternativa necesita su propia búsqueda.
4. **Si la búsqueda sale limpia**, una marca de la UE (EUIPO) cubre los 27 países; las tasas están en euipo.europa.eu.
