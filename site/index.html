Do not vibecode. Spellcode.

CodeWizards runs Claude Code on your computer, with your own plan, and shows its work as wizards in a pixel-art tower. Every spell becomes quests on their own branches, and you judge each change on the blackboard before it is committed.

Try the demoInstall

Free and open source. No server, no account, no telemetry. The demo runs in your browser and calls no model.

How a spell becomes a change

  1. Cast a spell. Write what you want in the spell book. Choose a wizard's rank, or leave it to the Archmage.
  2. The Archmage plans. It splits the spell into quests and picks each one's rank, model and effort: its rules, plus one short call to the cheapest model.
  3. Wizards work. Each quest gets a wizard: Claude Code, with your plan, in its own git worktree and branch, so your checkout is not touched. You watch it read at the library and write at the alchemy table.
  4. You judge. The wizard presents its diff, file by file, on the blackboard. Bless it and it is committed to the quest's branch; send it back with your words and the same wizard tries again.
  5. Seal it. Merge the blessed branch yourself, open a draft pull request, or let CodeWizards fast-forward it into your branch. It never forces a merge.

Your plan, your machine

CodeWizards is free. It runs on your computer and drives the official agent CLI, unmodified, under your own account: today Claude Code, with your Claude plan. The wizards spend that plan's usage, which the room shows as mana, and caps per quest and per room stop a runaway loop.

It never reads or stores your credentials, and it does not hand an API key to Claude Code unless you ask it to with --use-api-key. There is no CodeWizards server: your code goes where Claude Code sends it, as it would without the tower. Read the privacy policy.

Words of the tower

Every magic word stands for one technical thing and keeps its name everywhere. In the room, hover over a word to read what it means.

The guilds

One guild per model maker, each with a name, a colour and an emblem of its own. The maker is data: CodeWizards is not affiliated with any of them. The Amber Order works today; the others are planned.

Install

You need Node.js 22 or later and git. For real wizards, install Claude Code and sign in once; the demo needs neither. The GitHub CLI (gh) is only needed for draft pull requests.

  1. Install the tower.
    npm install -g codewizards
    Before the first npm release: npm install -g github:poligle/codewizards
  2. Open the demo. Simulated wizards: no agent, no account, no network.
    codewizards demo
  3. Check your tools. It looks for node, git, gh and claude without reading any credentials.
    codewizards doctor
  4. Open a room on a repository of yours.
    codewizards serve --repo ~/code/my-project
    Or just run codewizards: The Tower lists your rooms and founds new ones.

macOS and Linux are at home in the tower. On Windows the wizards get no Bash, because Claude Code's sandbox needs WSL2: run CodeWizards inside WSL2 for the full tower.
